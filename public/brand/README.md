# Ravaan Labs — Logo Asset Pack

Vector (SVG) and raster (PNG) exports of the Ravaan Labs mark, built as scalable
code so any piece can be recolored, resized, or re-composed later.

Brand gradient: `#22C4F5` (cyan) → `#3E7BFA` (blue) → `#7B3FE4` (violet)
Navy: `#0B0F1E` · Ink (body text on light): `#111827`
Typeface: Poppins (Bold for "RAVAAN", Medium for "LABS" and the tagline)

## What's in each folder

**svg/** — every asset as an editable vector source. Open in Illustrator,
Figma, or Inkscape to recolor, resize, or export at any resolution without
quality loss.

**png/primary-logos/** — full lockup (mark + wordmark + tagline), 1200×420
  - `primary-logo-dark.png` — on navy background
  - `primary-logo-light.png` — on white background
  - `primary-logo-transparent-dark-text.png` — transparent bg, dark text (for light surfaces)
  - `primary-logo-transparent-light-text.png` — transparent bg, white text (for dark/photo surfaces)

**png/app-icons/** — 512×512, rounded-square app icon format
  - `app-icon-dark.png`, `app-icon-light.png`, `app-icon-gradient.png`

**png/symbol-marks/** — the "R" mark alone, no wordmark, transparent unless noted
  - `symbol-mark.png` — gradient, transparent background (primary vector asset)
  - `symbol-mark-dark-bg.png` — on navy square
  - `symbol-mark-white.png` — solid white, transparent bg (for dark backgrounds/merch)
  - `symbol-mark-navy.png` — solid navy, transparent bg (single-color/print use)

**png/lockups/** — alternate compositions
  - `lockup-stacked-light.png` / `-dark.png` — mark centered above wordmark + tagline
  - `lockup-horizontal-divider-light.png` / `-dark.png` — mark | wordmark, no tagline (compact header use)
  - `lockup-stacked-dash-accent-light.png` — stacked, with dash accents flanking "LABS"
  - `lockup-circular-badge.png` — circular seal with "EXPERIMENT · BUILD · EVOLVE" arced over the mark

**png/favicons/** — browser and app favicon sizes
  - `favicon-16/32/48/64/128/256.png` — flat mark, transparent background
  - `favicon.ico` — multi-resolution ICO (16–256px) for direct use as `favicon.ico`
  - `favicon-circle-dark/light/gradient.png` — 128×128 circular badge variants, useful where a filled icon reads better at small sizes than a transparent one

**png/social-profiles/** — 400×400, pre-cropped to a circle for profile photos
  - `social-profile-dark.png`, `-light.png`, `-gradient.png`

## Usage notes

- Prefer the SVG files for anything that will be resized (web headers, print,
  merch) — they stay crisp at any scale.
- Use `symbol-mark.png`/`.svg` (transparent) as the base if you need a custom
  size or background not covered here.
- Keep clear space around the mark roughly equal to the width of the mark's
  stem on all sides when placing it near other logos or edges.
- Don't recolor the gradient itself; use the solid white/navy single-color
  versions when the gradient won't reproduce well (e.g. one-color print,
  embroidery, watermarks).
